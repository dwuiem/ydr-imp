# Yadro impulse test task 

### Usage
1. Клонирование
```sh
git clone https://github.com/dwuiem/ydr-imp.git
cd ydr-imp
```
2. Запуск программы
```sh
go run main.go
```
3. Запуск тестов
```sh
go test -v
```

### Идея решения
Мы имеем матрицу n*n, состоящая из контейнеров. Чтобы понять можно ли отсортировать шары 
согласно условию задачи представим ситуацию когда шары уже отсортированы. В таком случае контейнеры будут иметь вид
```
x1 0  0  ... 0
0  x2 0  ... 0
0  0  x3 ... 0
0  0  0  ... xn
```
Заметим, что в таком порядке контейнеров сумма мячей i-й контейнера равна сумме мячей i-го цвета

```
x1-1     1    0  ... 0
  1    x2-1   0  ... 0
  0      0    x3 ... 0
  0      0    0  ... xn
```
Также заметим, что при совершении **любого количества** допустимой операции (обмен мячами у любых двух разных контейнеров), 
контейнеры не теряют изначальное количество мячей и при этом оба цвета имеют то же количество мячей, т.е. сумма строк и столбцов сохраняется всегда.

Это означает, что если можно упорядочить входные контейнеры так, чтобы выполнялось свойство - сумма i-й строки равняется сумме i-го столбца, то 
при совершении некоторого количества допустимой операции над контейнерами можно отсортировать мячи по цвету и контейнерам.

### Алгоритм функции:

1. Инициализируем слайс который будет хранить количество мячей для каждого цвета и слайс который будет хранить количество мячей в каждом контейнере
2. Заполняем эти 2 слайса подсчётами сумм строк и столбцов в матрице соответственно.
3. Сортируем эти 2 слайса, чтобы упорядочить контейнеры так чтобы сумма i-й строки равняется сумме i-го столбца
4. Сравниваем 2 слайса поэлементно (равенство сумм), чтобы определить существует ли такой порядок контейнеров
5. Если отсортированные слайсы равны то функция возвращает true иначе false

Так как по условию количество шаров одного цвета может быть равно 0 то сумма строки (столбца) равная 0 считается валидной

**Time complexity**: O(n^2)  (линейно-логарифмическая сложность сортировки не превышает квадратичную сложность)  

**Space complexity (без учёта скана)**: O(n)
